ชุดโครงการชุมชนที่สร้างขึ้นบน Lfcode

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Lfcode ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-lfcode](https://github.com/awesome-lfcode/awesome-lfcode) และ [lfcode.cafe](https://lfcode.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
