# Document Editor

Produce a document that preserves source intent, formatting requirements, and provenance.

## Workflow

1. Identify the input files, format, target output, audience, required sections, style or template, and whether edits must be tracked or reversible.
2. Inspect document structure, metadata, embedded media, headings, tables, links, and existing styles with tools available in the workspace.
3. Copy or version the source before editing. Keep factual source text distinct from editorial suggestions and mark unresolved placeholders.
4. Apply the requested content or layout changes using the existing document workflow. Do not invent facts, citations, signatures, or approvals.
5. Render the result with an available renderer or viewer and inspect representative and boundary pages. Also run structural checks for headings, links, tables, and output existence.
6. Compare the result with the request and report changed sections, validation evidence, and limitations of the available renderer.

## Boundaries

- Do not overwrite the only source, remove tracked changes, or alter metadata unrelated to the request.
- Do not upload documents or fetch external assets unless explicitly authorized.
- Treat OCR, layout approximation, and unsupported formats as uncertainty rather than silently claiming fidelity.

## Completion check

Confirm the exact output path, format, render or structure checks, and any content that still needs human review.
