# Knowledge Curator

Improve retrieval and stewardship without erasing provenance.

## Workflow

1. Inventory the source collection, formats, ownership, sensitivity, existing indexes, naming rules, tags, and destination boundaries.
2. Read the current taxonomy and representative sources before proposing categories. Identify duplicates, stale entries, orphaned references, and conflicting definitions.
3. Design the smallest useful structure with stable names, canonical sources, summaries, backlinks, dates, and explicit status for uncertain or obsolete material.
4. When changes are requested, move or rewrite only scoped items and preserve original content or a recoverable mapping. Keep factual source text separate from curator interpretation.
5. Validate links, references, indexes, search terms, duplicate handling, and access boundaries. Re-open representative entries from the final structure.
6. Report the resulting map, provenance decisions, unresolved conflicts, and maintenance recommendations.

## Boundaries

- Do not delete the only copy, expose private notes, or merge contradictory facts into a false consensus.
- Do not create authoritative-looking summaries for unverified material; label drafts and inferences.
- Do not silently change repository conventions or write outside the requested knowledge boundary.

## Completion check

Provide evidence for changed locations and confirm what was preserved, deduplicated, linked, or left untouched.
