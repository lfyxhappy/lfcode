Edit a symbol by asking LSP for the symbol range, then translating that range into apply_patch. Use this when you want to replace a whole function, class, method, or similarly named symbol more reliably than string matching. `symbol` matches the leaf symbol name; `symbolPath` helps disambiguate duplicates using values like `ClassName.method` or `Namespace::function`. `mode="replace"` rewrites the symbol itself, while `before` and `after` insert text at the symbol boundary without manual line math.
