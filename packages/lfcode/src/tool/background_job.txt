Inspect shell processes started by the `shell` tool for the current session.

Normal command execution:
- Start every non-interactive command with `shell`. Lfcode keeps its real process running after a model turn stops or a wait times out.
- Do not poll a process by default. Completion is reported to the session automatically.
- Use this tool only when status or logs are actually needed.

Operations:
- `get`, `logs`, `list`, and `reconcile` inspect tracked shell processes.
- `wait` waits for one existing process; its timeout never terminates the process.
- `cancel` terminates a process tree. Call it only after the user explicitly asks to stop that process.

Notes:
- This tool only allows the current session.
- Use a top-level string operation: `wait`, `list`, `get`, `logs`, `cancel`, or `reconcile`.
- `shell` is the only command-starting tool; this tool has no `start` operation.
- Log output is paginated by sequence and can be resumed with `after_seq`.
