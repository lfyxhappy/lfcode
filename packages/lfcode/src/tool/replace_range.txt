Replace a known line/character range inside a text file. Use this for one precise edit after reading the current file. Lines and characters are 1-based; startChar is inclusive and endChar is exclusive. If startChar or endChar is omitted, the tool defaults to the start or end of that line. Internally this tool translates the range edit into apply_patch, so normal permissions, formatting, watcher updates, and LSP diagnostics still apply. If the range is uncertain, read the file again; do not guess.
