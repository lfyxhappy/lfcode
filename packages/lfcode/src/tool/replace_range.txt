Replace a known line/character range inside a text file. Use this for one precise edit after reading the current file. Lines and characters are 1-based; startChar is inclusive and endChar is exclusive. For a line of length N, valid endChar is 1 through N+1. If startChar or endChar is omitted, the tool defaults to the start or end of that line, so omitting both replaces whole lines. Internally this tool translates the range edit into apply_patch, so normal permissions, formatting, watcher updates, and LSP diagnostics still apply. If a coordinate error occurs, use its lineLength and maxEndChar exactly once; after a second coordinate failure, read the file again. If the range is uncertain, read the file again; do not guess.
