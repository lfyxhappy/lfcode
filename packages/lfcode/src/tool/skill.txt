Use this tool to inject a skill's instructions and bundled resources into the current conversation.

Do not use this tool just to ask what skills are currently available; that list is already present in the conversation context.
Use this tool when you need to search for a relevant skill by topic, or load one exact skill into the conversation.

If you pass an exact installed skill name, the tool loads it.
If you pass keywords instead, the tool returns matching skill candidates so you can load one by exact name in a second call.
