Use this tool to suggest switching to compose agent when the request is too large, ambiguous, or multi-stage for direct build mode.

Call this tool when:
- The work spans multiple subsystems, milestones, or architectural decisions
- The task would benefit from planning, decomposition, subagents, or staged review
- Requirements are incomplete enough that direct implementation would be risky
- The user is asking for a serious project rather than a localized edit

Do NOT call this tool:
- For simple, well-scoped bug fixes
- For straightforward small features
- For one-shot edits or quick investigations
- When the user explicitly wants to stay in build mode and implement directly
