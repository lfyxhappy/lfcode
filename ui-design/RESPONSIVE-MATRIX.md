# Responsive Matrix

| Region | 360-430px | 768-1024px | 1280px+ | Priority when space is tight |
|---|---|---|---|---|
| Header/navigation | compact titlebar, 44px controls, slide-over nav | full header and optional rail | persistent rail plus resize handle | current session and close/open nav |
| Main content | single column, Composer stays visible, long text wraps | flexible split with guarded min-widths | timeline plus optional panels | preserve primary session workflow |
| Sidebar/inspector | overlay at max 400px with semantic backdrop | collapsible side panel | persistent navigation and contextual rail | hide secondary context first |
| Table/list | stacked rows, truncation with title, no horizontal page scroll | dense rows with flexible columns | stable columns and scroll inside list | keep status/action column reachable |
| Primary actions | full-width or wrapped labels, 44px target | compact 36px target | compact 36px target | never hide core actions behind hover |
